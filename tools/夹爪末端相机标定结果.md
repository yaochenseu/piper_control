## 注意

- 这是单点接触标定，不是新的手眼标定；`T_flange_cam` 仍用 2026-10-28 的结果，未修改。
- 假设相机相对法兰的安装没有变；如果动过相机支架，这个结果不成立，需要先重做手眼。
- 接触点按 ChArUco 板中心 / ID 8 中心计算；如果实际碰的是别的码，需要改接触点。
- 末端坐标系姿态按与法兰相同处理；如果需要和夹爪开合方向对齐的末端系，还要再定义一个旋转。
- 抓取管线使用的 **pad-center TCP** 是 `flange_tcp_xyz_m: [0, 0, 0.1295]` + `Rz(90°)`，不是这里的夹爪尖端；不要把两者混用。
