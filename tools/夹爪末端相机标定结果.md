# 夹爪末端-相机标定结果（2026-10-24）

## 方法

- 示教模式下手动把闭合夹爪尖端放到 ChArUco 板中心
- 接触点取板中心 / 中间码 ID 8 中心，板坐标 `[105, 75, 0] mm`
- 相机测板位姿 + 机器人法兰位姿，取 2.5 s 平均
- 使用 2026-10-24 的 `T_flange_cam`（未修改）把接触点变换到法兰系
- 假设夹爪末端坐标系与法兰同姿态，只把原点移到接触点

## 结果

夹爪尖端在法兰系：

- 位置：`[+1.85, -3.91, +137.20] mm`
- 距法兰：`137.27 mm`
- 与模型 `[0, 0, 142.5] mm` 的差：`[+1.85, -3.91, -5.30] mm`，模长 `6.84 mm`
- 前进方向 137.2 mm 与 URDF 手指网格的 138 mm 很接近

夹爪尖端在相机系：

- 位置：`[+43.66, +34.54, +121.78] mm`

用旧 `T_flange_cam` 把板中心变换到 base 做校验：`[363.1, 121.9, -7.1] mm`，在桌面上，和手动接触点一致。

相机在夹爪末端系：

- 位置：`[-37.89, -78.92, -101.32] mm`
- RPY：`[-20.79, +0.35, +4.73]°`（与 `T_flange_cam` 相同，按上述姿态假设）

## 数据质量

- 相机板位姿：56 帧，抖动 0.02 mm / 0.01°
- 法兰位姿：501 帧，抖动 0.00 mm / 0.00°
- 画面里夹爪正好压在板中心 ID 8 的位置

## 注意

- 这是单点接触标定，不是新的手眼标定；`T_flange_cam` 仍用 2026-10-24 的结果，未修改。
- 假设相机相对法兰的安装没有变；如果动过相机支架，这个结果不成立。
- 接触点按 ChArUco 板中心 / ID 8 中心计算；如果你实际碰的是别的码，需要改接触点。
- 末端坐标系姿态按与法兰相同处理；如果需要和夹爪开合方向对齐的末端系，还要再定义一个旋转。
- 横向约 4.3 mm 的偏移可能来自真实指尖偏心、板中心估计或单点接触误差；要更高精度建议换几个姿态重复接触。
