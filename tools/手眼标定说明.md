# 手眼标定说明（eye-in-hand）

相机固定在机械臂末端，标定板固定在桌面。流程：

1. `aruco_detect` 用 OpenCV 检测 ChArUco 板，发布标定板在相机坐标系下的位姿 `/aruco_single/pose`
2. `calib` 同步接收 `/aruco_single/pose` 和驱动发布的 `/feedback/tcp_pose`
3. 采集多组后计算相机相对法兰的变换 `T_flange_cam`（驱动 `tcp_offset=0` 时 TCP 即法兰）

整套流程只依赖 OpenCV、RealSense ROS 驱动和机械臂驱动，**不需要 `aruco_ros` 或 `handeye_calibration_ros`**：`aruco_detect.py` 已替代前者的 single 节点，`calib.py` 自己实现手眼算法。

## 依赖

```bash
sudo apt install -y ros-humble-realsense2-camera python3-opencv python3-scipy python3-numpy
```

## 启动

终端 1，驱动：

```bash
ros2 launch agx_arm_ctrl start_single_agx_arm.launch.py \
  can_port:=can0 arm_type:=piper_x effector_type:=agx_gripper speed_percent:=15
```

终端 2，相机（1280×720，关闭深度）：

```bash
ros2 launch realsense2_camera rs_launch.py \
  rgb_camera.color_profile:=1280x720x30 enable_depth:=false
```

终端 3，标定板检测：

```bash
aruco_detect --board charuco --dictionary DICT_4X4_50 \
  --squares-x 7 --squares-y 5 \
  --square-length 0.03 --marker-length 0.022 --blur 3
```

确认检测正常：

```bash
ros2 topic hz /aruco_single/pose       # 应持续有输出
ros2 topic echo /aruco_single/pose --once
```

终端 4，开始采集：

```bash
calib
```

## 采集步骤

1. 另开一个终端，用 `arm` 把机械臂移动到第一个位姿，等完全停稳。
2. 在 `calib` 终端按 Enter 采集一组；终端会显示标定板距离和 TCP 抖动。
3. 改变末端位置和姿态，重复采集：
   - 至少 10 组，建议 15～22 组
   - 姿态最大夹角 > 20°，末端位置分散 > 80 mm
   - 标定板距相机保持 0.15～0.8 m
4. 输入 `q` 计算并保存；`d` 回退上一组；`c` 退出不保存。

## 结果

保存到 `tools/calib_results/<时间>_handeye.json`，终端同时打印：

- `T_flange_cam` 4×4 矩阵
- 平移/旋转一致性残差
- 可直接粘进 URDF 的 `<origin xyz rpy>` 写法

合格标准：

- 平移 RMS < 3 mm，旋转 RMS < 1°
- 姿态最大夹角 > 20°，末端位置分散 > 80 mm
- 平移量 |t| 不应大于 0.5 m

2026-10-24 的结果：平移 2.69 mm RMS、旋转 0.98° RMS，详见 `手眼标定结果.md`。

## 常见问题

| 现象 | 处理 |
|---|---|
| `标定板不可见` | 检查相机话题是否为 `/camera/camera/color/image_raw`；确认 1280×720；`--blur 3`；避免反光 |
| `/aruco_single/pose` 无输出 | `aruco_detect` 与相机必须在同一 `ROS_DOMAIN_ID`（脚本默认 42） |
| `没有收到足够的 /feedback/tcp_pose` | 驱动未启动，或 `ROS_DOMAIN_ID` 不一致 |
| 残差偏大 | 标定板不平/有移动、方格或码尺寸填错、采集时未停稳 |
| 姿态/位置多样性不足 | 增加不同方向的倾斜和位置，不要只平移 |
