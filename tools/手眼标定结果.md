## 触碰验证（可选）

板中心 `[360.9, 118.3, -4.2] mm`，指尖偏移 142.5 mm。以下命令保持当前姿态（RPY `[-149.11, 2.50, -72.75]°`），只改法兰位置；先加 `-n` 预演，确认后再去掉 `-n` 执行。J4 会从约 76° 降到约 20°，注意周围空间。

```bash
# 指尖在板中心上方 100 mm（先预演）
arm p 292.6 91.5 218.0 -149.11 2.50 -72.75 -n

# 确认后执行
arm p 292.6 91.5 218.0 -149.11 2.50 -72.75 -w 60

# 上方 50 mm
arm p 292.6 91.5 168.0 -149.11 2.50 -72.75 -l -w 60

# 上方 20 mm
arm p 292.6 91.5 138.0 -149.11 2.50 -72.75 -l -w 60

# 上方 5 mm
arm p 292.6 91.5 123.0 -149.11 2.50 -72.75 -l -w 60

# 触到板中心
arm p 292.6 91.5 118.0 -149.11 2.50 -72.75 -l -w 60

# 退回 50 mm
arm p x x x+50 -l -w 60
```

每步后可用 `arm_state` 核对指尖位置：上方 50 mm 时应约为 `[360.9, 118.3, 45.8] mm`，触板时应约为 `[360.9, 118.3, -4.2] mm`。若 `arm p` 报 IK/限位错误，不要继续下降。

## 注意

- 标定板必须固定不动，板面尽量平；硬纸板当前 0.27 px 重投影、残差 2.69 mm/0.98°，可以接受。
- 若要更高精度，把打印纸贴到玻璃/亚克力等更硬的平板上，并保持哑光、无强反光。
- 采集时必须等机械臂完全停稳（≤0.8 mm / 0.25° 持续 1 s），否则残差会明显变大。
- 相机使用 1280×720 + 3×3 模糊；640×480 下这些小码容易漏检。
