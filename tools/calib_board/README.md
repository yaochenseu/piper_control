# A4 ChArUco 标定板

文件：

- `charuco_A4_7x5_30mm_22mm.pdf`：用于打印（A4 横向）
- `charuco_A4_7x5_30mm_22mm.png`：300 DPI 原图
- `preview.png`：低分辨率预览

## 打印要求

1. 纸张 A4，横向打印。
2. 打印缩放必须选 **100% / 实际大小**，不能选“适应页面 / Fit to page”。
3. 打完用尺子量一下顶部的 **100 mm** 校验线，必须是 100 mm；不是就重新打印。
4. 用哑光纸，避免反光；不要覆亮膜。
5. 打印后整张纸贴在一块硬平板上（亚克力、玻璃、硬纸板、书本封面均可），
   四边贴牢，板面不能有起伏。**纸面不平会直接变成标定残差。**

## 板参数

| 项目 | 值 |
|---|---|
| 方格 | 7 × 5 |
| 方格边长 | 30 mm |
| ArUco 码边长 | 22 mm |
| 字典 | DICT_4X4_50 |
| 板尺寸 | 210 × 150 mm |
| 页面 | A4 横向 297 × 210 mm |

参数也保存在 `board.json` 中。

## 检测

相机和驱动启动后，用 ChArUco 模式：

```bash
aruco_detect --board charuco
```

它仍然发布 `/aruco_single/pose`，所以 `calib` 不用改：

```bash
calib --min 20
```

板子的位姿原点是板子自身的坐标系原点（不是板中心），对手眼标定没有影响。
