# 机械臂控制说明

命令：`arm`（`~/agx_arm_ws/tools/arm.sh`，自动加载 ROS 环境）

`j` = 关节角控制，`p` = 笛卡尔位姿控制。默认直接执行，加 `-n` 只预演。

> **MoveIt 运行期间请用 `armplus` / `armpro`，不要用 `arm`。**
> MoveIt 的 ros2_control 会以 200 Hz 发布 `/control/joint_states`，
> 驱动会持续执行这个流，`arm` 发的 `/control/move_j` 会被它覆盖。

| 场景 | 命令 |
|---|---|
| 未启动 MoveIt，直接控制驱动 | `arm` |
| MoveIt 运行，控制器直连（不规划） | `armplus` |
| MoveIt 运行，MoveIt 规划执行 | `armpro` |

三个命令的语法、单位一致（度 / 毫米 / 夹爪比例）。
`armplus` / `armpro` 的夹爪力 `-f` 不生效，固定约 1.0 N。
MoveIt 相关用法见 `MoveIt控制说明.md`。

---

## 1. 关节控制（j）

```bash
arm j <j1> <j2> <j3> <j4> <j5> <j6> [夹爪比例] [选项]
```

| 参数 | 说明 |
|---|---|
| 关节角 | 单位：度（°） |
| 夹爪比例 | 0=闭合，0.5=半开，1=全开 |
| `-f` | 夹爪力，0.5~3.0 N，默认 1.0 |
| `-c` | 超出限位时自动夹紧（默认拒绝） |
| `--md` | 可选：单次变化保护（度） |
| `-n` | 只预演 |

```bash
# joint3 改到 -30°，其余保持
arm j x x -30 x x x

# joint1 当前 +10°
arm j x+10 x x x x x

# 夹爪张开一半
arm j x x x x x x 0.5 -f 1.0

# 只预演（选项可放前面或后面）
arm j -n x x -30 x x x
```

---

## 2. 位姿控制（p）

```bash
arm p <x> <y> <z> [rx ry rz] [夹爪比例] [选项]
```

| 参数 | 说明 |
|---|---|
| `x y z` | 位置，单位：毫米（mm） |
| `rx ry rz` | 姿态，单位：度（°）；不填保持当前 |
| `-l` | 直线运动 `move_l`（默认 `move_p` 点到点） |
| `-n` | 只预演 |

```bash
# z 抬高 10 mm
arm p x x x+10

# 绝对位姿 + 姿态
arm p 96.9 0 300 -85 0 -90

# 直线运动
arm p 96.9 0 300 -85 0 -90 -l
```

---

## 3. 目标写法

| 写法 | 含义 |
|---|---|
| `30` | 绝对目标 30 |
| `x` | 保持当前值 |
| `x+10` | 当前值 +10 |
| `x-10` | 当前值 -10 |

位置单位 mm，关节角和姿态单位度。

---

## 4. 其他选项

| 选项 | 说明 |
|---|---|
| `-t` | 目标（可省略，直接写在 j/p 后面） |
| `-f` | 夹爪力（N） |
| `-n` | 只预演，不发送 |
| `-w` | 执行后监控秒数，默认 3.0 |
| `--jn` | 关节数（Piper=6，Nero=7） |
| `--rb` | 型号，默认 piper_x |

---

## 5. 结果提示

最后一行：

```text
✅ 成功：已到达目标
❌ 失败：arm_status=4（目标角度超限）
⚠️ 状态成功但误差偏大
```

判定：`arm_status != 0` 或 `motion_status != 0` 为失败；
关节误差 > 2°、位置误差 > 2 mm 或姿态误差 > 0.5° 为警告。

---

## 6. 速度

- 机械臂速度由驱动 `speed_percent` 控制，当前默认 **15%**
- 夹爪没有独立速度参数；`-f` 是夹持力上限，不是速度
- 夹爪速度由夹爪固件决定
